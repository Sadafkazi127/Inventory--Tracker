Build a full-stack web application called Inventory & Billing Software for Local Shops using the following technology stack:

Tech Stack
	•	Frontend: React + TypeScript
	•	Styling: Tailwind CSS + shadcn/ui
	•	Backend: Supabase
	•	Database: Supabase PostgreSQL
	•	Authentication: Supabase Auth (Email & Password)
	•	Charts: Chart.js
	•	PDF Generation: jsPDF + AutoTable

The application should have a modern, clean, responsive dashboard similar to professional POS (Point of Sale) software. Use a blue and white color theme with rounded cards, professional tables, icons, and responsive layouts.
